# RF Swarm — загрузки

Здесь лежат только готовые сборки программы RF Swarm (мультибокс для RF Online). Исходного кода в этом репозитории нет.

**Скачать последнюю версию:** раздел [Releases](../../releases/latest) → файл `RF_Swarm_vX.XXX.exe`.

- Для работы нужен лицензионный ключ — без него программа не запустится.
- Требования: Windows 10/11 (64-bit).
- Официальный канал: https://t.me/RF_Swarm
- Купить или продлить подписку: https://funpay.com/users/106707/
